# Décisions

Journal des décisions du projet. Chaque fichier décrit une décision : contexte, choix, raisons,
conséquences. Une décision remplacée n'est pas supprimée : on écrit une nouvelle décision qui
indique « remplace la 000X » et on met le statut de l'ancienne à jour.

Format d'un fichier : Statut, Date, Contexte, Décision, Raisons, Conséquences.
