    Tester sur macOS

    1. MediaMTX (UDP 8189 indispensable pour le média WebRTC) :

    docker run --rm -it -e MTX_RTSPTRANSPORTS=tcp -e MTX_WEBRTCADDITIONALHOSTS=127.0.0.1 -p 8554:8554 -p 8889:8889 -p 8189:8189/udp bluenviron/mediamtx:1

    2a. Source de test (mire 720p60, H.264 sans images B) :

    docker run --rm jrottenberg/ffmpeg:7.1-ubuntu -re -f lavfi -i testsrc2=size=1280x720:rate=60 -c:v libx264 -preset ultrafast -tune zerolatency -profile:v baseline -pix_fmt yuv420p -g 60 -f rtsp -rtsp_transport tcp rtsp://host.docker.internal:8554/sim-1

    2b. Ou OBS : Paramètres, Stream, service WHIP, serveur http://localhost:8889/sim-1/whip, puis capture de cette fenêtre pour mesurer le retard.
